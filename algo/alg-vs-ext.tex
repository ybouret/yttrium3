\section{Problem}

We start form a given $h_0$ and want to know the new value
after the addition of strong acid/base with concentration $\delta$.


\section{Algebraic Result, Fully Dissociated Electrolytes Only}

We start from:
\begin{equation}
h_0-K_w/h_0 + A_0 = 0
\end{equation}

The new solution is:
\begin{equation}
h-K_w/h + (A_0+\delta) = 0 
\end{equation}

\section{Chemical Extent, Fully Dissociated Electrolytes Only}

\subsection{Acid: $\delta<0$}

\begin{equation}
	h=h_0-\delta+\xi,\;w=K_w/h_0 + \xi
\end{equation}
and we need to solve:
\begin{equation}
	h \cdot w = K_w = (h_0-\delta+\xi) (K_w/h_0 + \xi)
