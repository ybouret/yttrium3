\section{Problem}

We start form a given $h_0$ and want to know the new value
after the addition of strong acid/base with concentration $\delta$.


\section{Algebraic Result, Fully Dissociated Electrolytes Only}

We start from:
\begin{equation}
h_0-K_w/h_0 + \sigma_0 = 0
\end{equation}

The new solution is:
\begin{equation}
\left\lbrace
\begin{array}{l}
h-K_w/h + (\sigma_0+\delta) = 0  \\
\text{$\delta<0$ for an acid} \\
\text{$\delta>0$ for a base} \\
\end{array}
\right.
\end{equation}

\section{Chemical Extent, Fully Dissociated Electrolytes Only}
